# Raft Survive（紧张木筏求生）

手机 / iPad 上的**紧张向**海上木筏求生游戏设计文档仓库。引擎：**Godot 4**。

> 一句话：在波涛与匮乏中，用最简单的触控抛钩打捞、撑过 3～5 分钟的短关卡。

## 技术要点（摘要）

- **平台**：iPhone / Android 手机 + iPad
- **引擎**：Godot 4（2D 优先）
- **基调**：紧张求生，非 cozy
- **单局时长**：每关 / 每段 **3～5 分钟**
- **存档**：允许手动存档；自动存档默认 **60 秒**（可选 30 秒）

设计文档仅作项目规划用途；具体开源许可待项目代码阶段再定。
