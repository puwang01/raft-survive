# 试玩 · Level 1 原型（HTML5）

无需安装 Godot。用手机 / iPad / 电脑浏览器即可试玩第 1 关垂直切片。

## 怎么打开

### 方式 A：直接打开（最简单）

用浏览器打开本目录的 `index.html`（双击，或拖进 Chrome / Safari / Edge）。

> 若浏览器拦截 `file://` 本地存储，请改用方式 B。

### 方式 B：本地小服务器（推荐）

在仓库根目录或本目录执行：

```bash
cd play
python3 -m http.server 8080
```

然后在浏览器打开：<http://localhost:8080/>

手机同一 Wi‑Fi 下可用电脑 IP 访问，例如 `http://192.168.x.x:8080/`。

## 操作

| 操作 | 说明 |
|------|------|
| 拖动松手 | 瞄准并抛钩 |
| 收回钩 | 未挂住时手动收回 |
| 吃喝 | 消耗打捞到的食物 / 淡水 |
| 暂停 | 手动存档 / 读档 / 重开 |

## 第 1 关目标

- **胜利**：收集 **5 块浮木**（限时约 4 分钟）
- **失败**：生命归零，或时间耗尽且未凑齐浮木
- 口渴下降最快；饥/渴归零后掉血
- 约 45 秒后或收集较多浮木时，鲨鱼会开始靠近撞击

## 存档

- 暂停菜单 → **手动存档**
- **每 60 秒**自动写入浏览器 `localStorage`
- 切到后台时也会强制存一次

## 与 Godot 的关系

本目录是 **try-now** 可玩原型（Canvas）。正式引擎仍为 **Godot 4**，骨架在仓库 [`godot/`](../godot/)。玩法验证后再把抛钩 / 生存 / 关卡逻辑迁入 Godot 场景。
