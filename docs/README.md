# 设计文档目录

本目录存放 **Raft Survive**（紧张木筏求生）的设计文档。语言：简体中文（zh-Hans）。

## 目录

1. [愿景与定位](01-game-vision.md) — 一句话设定、紧张求生基调、目标平台、引擎、非目标
2. [核心循环](02-core-loop.md) — 抛钩→打捞→资源→生存压力→短关卡→结算
3. [操作与 UX](03-controls-and-ux.md) — 触控方案、手机/iPad 布局、上手难度原则
4. [关卡与节奏](04-levels-and-pacing.md) — 3～5 分钟关卡结构、目标示例、难度递进
5. [存档系统](05-save-system.md) — 手动存档、自动存档 30s/60s、存档内容与移动端写入策略
6. [Godot 项目结构](06-godot-project-structure.md) — Godot 4 目录与场景拆分、实现优先级
7. [待定项](07-open-questions.md) — 尚未决定的设计问题与当前默认假设

## 阅读顺序建议

新同学建议按编号顺序阅读。若只关心玩法，读 01→02→04；若只关心工程落地，读 05→06→07。

## 变更约定

- 文档变更请用清晰的 commit message（中文或英文均可）。
- 拍板后的决策请从 `07-open-questions.md` 移入对应正文，并在 07 中标记为「已决议」。
