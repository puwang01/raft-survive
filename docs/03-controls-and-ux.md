# 03 — 操作与 UX

## 上手难度原则

1. **最简单的控制**：核心动作尽量「单指、单步」。
2. **大按钮、大热区**：建造、背包、存档入口的触控面积按拇指设计，避免边缘误触。
3. **零 thrash 教程**：前 30 秒用情境提示（箭头 / 高亮漂流物），不强制长文案。
4. **危险可见**：血/饥/渴过低时用颜色、脉冲、短震动（若系统允许）提示，不靠小字。

## 触控方案（手机）

### 核心：单指瞄准抛钩

- **推荐手势**：在「可抛钩区域」（屏幕下半或右侧海面）按下并拖动显示抛物线预览，松手抛出。
- **备选（更简单）**：点按海面一点即朝该方向以默认力度抛出；长按蓄力（可选，默认关闭以免增加复杂度）。
- **收回**：钩子挂住后自动拉回；未挂住时点按「收回」大按钮或再次点海面。

避免：双摇杆、多指手势、精确角度微操。

### 建造与背包

- 屏幕底部或侧边：**建造**大按钮 → 弹出 2～4 个当前可造物（灰显不可造）。
- **背包**：另一大按钮；格子偏大，拖拽合成仅在必要时出现，优先「点选材料 → 点合成」。
- 放置木板扩展筏面：选中建材后点筏边缘高亮位「一键放下」。

### HUD 布局（竖屏示意）

```
┌─────────────────────┐
│ ❤ ❤ ❤   🍖 ██  💧 ██ │  ← 生存三维（顶栏，始终可见）
│ 目标：浮木 3/5   ⏱4:12 │
│                         │
│         （海面）         │
│                         │
│      [木筏 + 玩家]       │
│                         │
│  [背包]     [建造] [收回] │  ← 底部拇指区
│  [暂停/存档]             │

```

## iPhone vs iPad 布局差异

| 项目 | iPhone（小屏） | iPad（大屏） |
|------|----------------|--------------|
| 方向 | 默认竖屏 | 竖/横均可；横屏可把建造栏固定在右侧 |
| HUD | 顶栏紧凑，图标优先 | 可显示文字标签与次要目标 |
| 建造 UI | 全屏半遮罩列表 | 侧栏常驻 3～4 快捷建造 |
| 安全区 | 避开刘海 / Home 指示条 | 利用左右边距放次要按钮 |
| 字体与热区 | 最小可点约 44pt | 可略增大，减少误触 |

同一套逻辑控件，用 Godot 主题 / 锚点做**响应式布局**，不要维护两套玩法。

## 辅助与无障碍（首版可简）

- 色弱：生存条除颜色外加形状/图标区分。
- 可关闭屏幕震动。
- 可选「简化抛物线」：始终直线短距钩（降低操作门槛的辅助模式）。

## 暂停与存档入口

- 暂停菜单内提供：**继续 / 手动存档 / 读档 / 设置 / 退出关卡**。
- 手动存档入口必须在暂停中一眼可见（详见 05）。
