# 07 — 待定项（Open Questions）

下列问题尚未最终拍板。文档其他处已采用**当前默认假设**，便于开工；决议后请更新对应正文并在此标记。

## 存档间隔默认：30 秒还是 60 秒？

- **当前默认**：**60 秒**自动存档；设置中可选 30 秒或关闭。
- 理由：移动端闪存写入、电量与卡顿；短关卡下 60s 已能覆盖多数切应用场景，再加「进后台强制存」。
- 待验证：真机上 30s 是否可接受；若存档体积极小且异步写无感，可再改为默认 30s。

## 视角：纯 2D 俯视 vs 微仰视 / 2.5D？

- **当前默认**：**2D 偏俯视**（可轻微斜视美术），逻辑按 2D 网格筏面实现。
- 备选：Y 轴略倾斜的「微仰视」增强体积感，但仍用 2D 碰撞与导航。
- 待决因素：美术风格试验、钩子可读性、制作成本。

## 胜利条件：救援 vs 跳岛 vs 其他？

- **当前默认（叙事骨架）**：中期以「组装并发射求救信号」为里程碑；全章结局倾向 **被路过船只/直升机救援**。
- 备选：跳岛建立临时营地（可能拉长单局，与 3～5 分钟冲突，更适合「章节间过场」而非单关目标）。
- 待决：首版第一章只做到「发出信号」即可，完整救援动画可后置。

## 关卡间木筏是否继承？

- **当前默认**：同一**章节内**继承筏布局与部分库存；**大章切换**时给加固版预设筏，避免存档膨胀与难度失控。
- 待决：是否提供「无尽挑战模式」共用持久筏（非首版必做）。

## 竖屏锁定还是允许横屏？

- **当前默认**：手机**竖屏优先**；iPad 支持横屏侧栏建造。
- 待决：是否在设置中开放手机横屏（需重排 HUD）。

## 鲨鱼交互深度？

- **当前默认**：首版鲨鱼以「驱离 / 吓退 / 造成甲板伤害」为主，不做复杂水下战。
- 待决：是否引入简易「矛」一次性道具。

## 多人？

- **当前默认**：**单机**。
- 不做联机，除非日后单独评估。

## 商业化 / 广告？

- 未定。设计文档阶段不绑定 IAP 或广告点；若日后加入，不得破坏 3～5 分钟紧张节奏（例如禁止关卡中强制插屏）。
