# 02 — 核心循环

## 循环一览

```
抛钩瞄准 → 打捞漂流物 → 获得资源
                ↓
        扩展 / 维修木筏、合成消耗品
                ↓
     生存压力（血 / 饥 / 渴）持续加压
                ↓
     短关卡目标达成 / 失败 → 结算 → 下一关或重开
```

## 分步说明

### 1. 抛钩（Hook）

- 玩家用**单指**在海面方向滑动或点击瞄准，松手 / 点击确认抛出钩子。
- 钩子沿轨迹飞出，碰到可打捞物则挂住并自动拉回（或短按收回）。
- 设计原则：**一次触控完成「瞄准 + 抛出」**，避免多键组合。

### 2. 打捞与资源

常见漂流物（首版示例）：

| 类型 | 用途 |
|------|------|
| 浮木 / 木板 | 扩展筏面、修补 |
| 塑料桶 / 绳索 | 合成、固定结构 |
| 食物残骸 / 椰子 | 缓解饥饿 |
| 淡水容器 | 缓解口渴 |
| 废铁 / 布料 | 工具、信号装置 |

稀有物可绑定关卡目标（如「信号弹零件」）。

### 3. 生存压力（三维）

- **生命（Health）**：受伤、溺水边缘、鲨鱼撕咬、饥饿/口渴归零后持续掉血。
- **饥饿（Hunger）**：随时间下降；过低影响生命与操作稳定性（可选轻度晃动/瞄准惩罚）。
- **口渴（Thirst）**：下降通常快于饥饿；风暴中可加速消耗（盐雾/体力）。

数值应让玩家在 **3～5 分钟**内至少做 **2～3 次**明确的「救饥 / 救渴 / 维修」决策，而不是全程无脑抛钩。

### 4. 短关卡目标

每关给出 1 个主目标 + 可选次要目标（详见 04），例如：

- 收集浮木 N/M
- 撑过一场限时风暴
- 组装并发射信号装置

### 5. 结算

- **胜利**：目标完成 → 简短结算（资源结余、受伤次数、用时）→ 解锁下一关或叙事推进。
- **失败**：生命归零 / 筏解体 / 超时未完成强制目标 → 失败原因一句话 + **一键重开本关**。

## 单局节奏（3～5 分钟）

| 时段 | 大约时长 | 玩家感受 |
|------|----------|----------|
| 开局适应 | 0～30s | 抛第一钩、看清 HUD |
| 资源积累 | 30s～2.5min | 打捞、吃喝、小幅扩建 |
| 压力高潮 | 最后 1～2min | 风暴/鲨/目标倒计时叠加 |
| 结算 | ～10～20s | 胜负清晰，立刻可再开 |

## 失败与重开

- 失败惩罚以**时间与情绪**为主：不设重度永久损失（首版）；关卡进度保留到「已通过的最高关」。
- 手动存档允许玩家在关卡内安全点留下进度（见 05）；失败后可从最近手动/自动存档恢复，或选择「本关重来」。
- 重开必须 **≤2 次点击** 回到可玩状态。
