# 04 — 关卡与节奏

## 结构原则

- **每关 / 每个 run 段落最长 3～5 分钟**（含高潮，不含结算动画）。
- 章节由若干短关串联；章节之间可有极短叙事或解锁新配方。
- 玩家可随时暂停、手动存档；自动存档在后台默默进行。

## 关卡模板

每关包含：

1. **主目标**（必须完成才能过关）
2. **环境节拍**（天气 / 时段 / 威胁何时出现）
3. **资源表**（本关刷什么、刷多少）
4. **失败条件**（生命归零、筏关键块过少、主目标超时等）

## 目标示例

| 关卡意向 | 主目标 | 次要目标（可选） |
|----------|--------|------------------|
| 教程关 | 打捞浮木 3/3，铺出第 2 块甲板 | 吃掉 1 份食物 |
| 渴压关 | 获得并饮用淡水，存活至倒计时结束 | 不让口渴低于 20% |
| 风暴关 | 在风暴中撑过 90 秒且筏至少保留 4 格 | 修补破损 1 次 |
| 信号关 | 收集零件并组装「简易信号装置」 | 在黄昏前完成 |
| 鲨影关 | 击退或吓退 1 次鲨鱼接近（用矛/噪音） | 零受伤通关 |

## 难度递进（白天 → 傍晚 → 鲨 / 浪）

| 阶段 | 时段/氛围 | 压力来源 | 玩家应学会 |
|------|-----------|----------|------------|
| 第 1～2 关 | 晴朗白天 | 饥渴慢扣、资源稀疏 | 抛钩与吃喝 |
| 第 3～4 关 | 午后起风 | 浪打断站位、物品漂得更快 | 优先目标物 |
| 第 5～6 关 | 傍晚 | 视野变差、口渴加速 | 资源取舍 |
| 第 7+ 关 | 阴天 / 夜缘 | 鲨鱼巡游、强风暴 | 扩建+武器/驱离 |

递进靠**威胁叠加**与**目标收紧**，而不是靠复杂操作技巧。

## 时间盒设计技巧

- 关卡开始即显示倒计时或「阶段条」（若该关有时限）。
- 无明确时限的关卡，用环境事件（3 分钟时强制入风暴）保证不会拖过 5 分钟。
- 若玩家提前完成主目标，允许**提前结算**（奖励「快速过关」小加成），避免无意义刷漂流物。

## 章节与 meta 进度

- 通关记录：已解锁关卡、最佳用时、是否无伤等（轻量）。
- 配方解锁绑在章节节点，避免单关内 UI 过载。
- 不做跨关卡的重度基地建造持久世界（与「短关卡」冲突）；筏布局可在「章节内」继承，跨大章时可部分重置或给预设加固筏（待 07 决议）。
