# 01 — 愿景与定位

## 一句话设定

你困在一片无情大海上的**小木筏**上：用钩子打捞漂浮残骸，盯着血量 / 饥饿 / 口渴，在风暴与鲨鱼逼近前撑过**短短几分钟**，活下去、造下去、发出求救信号——或葬身波涛。

## 参考语境（截图气质）

参考 Raft 类画面气质：玩家站在简陋木筏上，用钩子拉回浮木与漂流物；HUD 上有生命、饥饿、口渴；需要收集材料、建造扩展筏面、管理背包。  
**本项目取其「海上木筏 + 钩子打捞 + 三维生存条」骨架，但刻意做成更短、更紧、更适合触控的手机/iPad 体验，而不是 PC 开放世界沙盒的缩小版。**

## 基调：紧张求生（非 cozy）

| 要做 | 不做 |
|------|------|
| 资源始终偏紧，抉择有代价 | 悠闲装饰、无压力建造沙盒 |
| 天气 / 浪 / 鲨带来压迫感 | 纯治愈、轻松挂机 |
| 失败有清晰反馈，鼓励再开一局 | 无尽闲逛、无胜负感 |
| UI 信息明确、警告醒目 | 过度可爱、弱化危险提示 |

视觉与音效方向：偏冷色与高对比告警；海浪与金属钩声突出「危机感」而非「度假感」。

## 目标平台

- **主力**：智能手机（竖屏优先，可考虑横屏选项）
- **同等重要**：iPad（更大触控区、可展示更多 HUD / 建造按钮）
- 发行目标按 Godot 移动导出链路设计（iOS / Android）

## 引擎

- **Godot 4**（用户原文「Gotdot」校正为 Godot）
- 优先 **2D**（或 2.5D / 微俯视），降低移动端性能与内容制作成本（详见 06、07）

## 核心体验支柱

1. **极简操作**：单指抛钩瞄准；大按钮建造；几乎零教程负担。
2. **短局高压**：每关 / 每段 **3～5 分钟**，通勤可玩、失败可立刻重开。
3. **生存张力**：血 / 饥 / 渴持续扣减；环境威胁递进。
4. **可靠存档**：手动存档 + 自动存档（默认 60s，可选 30s）。

## 明确非目标（Out of Scope）

- ❌ 不做完整开放世界 / 无尽沙盒（对标 PC 版 Raft 的广度）
- ❌ 不做复杂多技能树、深度经济系统（首版）
- ❌ 不做强依赖精细 3D 操作的玩法
- ❌ 不做强制联机 / 强社交（单机优先）
- ❌ 不做超长单局（>5～10 分钟的连续无缝段落）

首版成功标准：**3 分钟内玩家理解「抛钩→活命→过关」**，并愿意因「差一点撑过去」而再开一局。
